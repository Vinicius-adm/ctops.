TROUBLESHOOTING COMUM:

  Problema: "Cannot connect to database"
  Solucao: docker-compose down -v && docker-compose up -d
           (Aguarde 15 segundos antes de tentar novamente)

  Problema: "Port 3001 already in use"
  Solucao: Stop-Process -Id (Get-NetTCPConnection -LocalPort 3001).OwningProcess

  Problema: "npm install fails"
  Solucao: npm cache clean --force && npm install

  Problema: Docker nao inicia
  Solucao: Reinicie o Docker Desktop ou seu PC
